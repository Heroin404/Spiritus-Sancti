Spartak Fan - мод для Minecraft 1.20.4 (Fabric)

Сборка локально:  gradlew build   ->  build/libs/spartakfan-1.0.0.jar
Тест в игре:      gradlew runClient
Сборка без установки чего-либо: загрузите эту папку в репозиторий GitHub,
вкладка Actions -> build -> Artifacts (там будет jar).

Для игры нужны: Fabric Loader + Fabric API (1.20.4).
Яйцо: креатив -> вкладка "Яйца призыва", или /summon spartakfan:spartak_fan
